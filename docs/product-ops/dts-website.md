# DTS Website Management

## Basics

Issues appear on the [_Projects_](https://austinmobility.io/projects), [_Products_](https://austinmobility.io/products)_, or_ [_Services_](https://austinmobility.io/services) webpages if they are assigned to any of those three issue types. We prepend the issue title with the issue type and a colon to make it identifiable at a glance.&#x20;
