### When do I use an _epic_ instead of a _task_ with subissues?

Epics and parent tasks are both useful for bundling issues into hierarchies for organizational purposes. Product managers and team leads may use an epic to record a start date and end date so that the collection of work is visible in a GitHub projects [roadmap view](https://github.com/orgs/cityofaustin/projects/27/views/5).
{% endhint %}
