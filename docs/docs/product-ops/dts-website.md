# Managing the DTS Website

We use the Data & Technology Services website, [Austinmobility.io](https://austinmobility.io), to showcase our work and communicate with stakeholders.

## Basics

Issues appear on the [_Projects_](https://austinmobility.io/projects), [_Products_](https://austinmobility.io/products)_, or_ [_Services_](https://austinmobility.io/services) webpages if they are assigned to any of those three issue types. We prepend the issue title with the issue type and a colon, e.g. "Product:" to make it identifiable at a glance when working in GitHub, but the website strips those from the issue title.&#x20;
